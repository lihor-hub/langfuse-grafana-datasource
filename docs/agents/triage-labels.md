# Triage labels

The engineering skills use five canonical triage roles. This repository maps
each role to the identically named GitHub label.

| Role              | GitHub label      | Meaning                                         |
| ----------------- | ----------------- | ----------------------------------------------- |
| `needs-triage`    | `needs-triage`    | Maintainer needs to evaluate the issue          |
| `needs-info`      | `needs-info`      | Waiting for information from the reporter       |
| `ready-for-agent` | `ready-for-agent` | Fully specified and safe for AFK implementation |
| `ready-for-human` | `ready-for-human` | Requires human judgment or implementation       |
| `wontfix`         | `wontfix`         | Will not be actioned                            |

An issue must not carry more than one of these workflow labels at a time.
