# Support

This project is maintained on a best-effort basis and does not provide a
response-time or resolution-time service-level agreement.

| Need | Where to go |
| --- | --- |
| Reproducible plugin defect | Use the repository bug-report issue form |
| Focused feature request | Use the repository feature-request issue form |
| Suspected vulnerability | Follow [Security](SECURITY.md); never open a public issue |
| Grafana product or deployment question | Use the [Grafana community and support resources](https://grafana.com/community/) |
| Langfuse API, server, or deployment question | Use the [Langfuse documentation and support resources](https://langfuse.com/docs) |

Before filing a plugin issue, search
[existing issues](https://github.com/lihor-hub/langfuse-grafana-datasource/issues)
and collect exact component versions and reproduction steps. Use synthetic data
and redact credentials, private hosts, personal information, and customer
observability data.

The repository is pre-release. Issues are welcome, but installation and upgrade
support will begin only after a verified release artifact exists.
